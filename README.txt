สมุดติดตามการเรียน (PWA)
=======================
ไฟล์ในโฟลเดอร์นี้:
  index.html            ตัวแอป
  manifest.webmanifest  ข้อมูลติดตั้งแอป
  sw.js                 ทำให้ใช้งานออฟไลน์ได้
  icons/                ไอคอนแอป

ต้องเปิดผ่านเว็บ (https) ถึงจะติดตั้งเป็นแอปได้ เปิดไฟล์ index.html ตรง ๆ ยังใช้งานได้ แต่ติดตั้งไม่ได้

วิธีที่ 1: GitHub Pages (ฟรี ใช้ได้ทุกเครื่องรวมถึง iPad)
  1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (แตกไฟล์ zip ก่อน)
  2. Settings > Pages > Source: Deploy from a branch > main > / (root) > Save
  3. รอสักครู่ จะได้ลิงก์ https://ชื่อผู้ใช้.github.io/ชื่อrepo/
  4. เปิดลิงก์บนมือถือ/แท็บเล็ต แล้วติดตั้ง

วิธีที่ 2: Netlify Drop (ไม่ต้องมีบัญชี GitHub)
  1. แตกไฟล์ zip แล้วเปิด https://app.netlify.com/drop
  2. ลากทั้งโฟลเดอร์ไปวาง ได้ลิงก์ https ทันที

วิธีที่ 3: Termux (ใช้ในเครื่องเดียว)
  cd โฟลเดอร์นี้
  python -m http.server 8080
  เปิด http://localhost:8080 ใน Chrome แล้วเลือก "ติดตั้งแอป" / "เพิ่มลงหน้าจอหลัก"
  (ต้องเปิด Termux ค้างไว้ตอนเปิดแอปครั้งแรก หลังติดตั้งแล้วใช้ออฟไลน์ได้)

การติดตั้ง
  Android (Chrome): ตั้งค่าในแอป > ติดตั้งแอป หรือเมนู ⋮ > ติดตั้งแอป
  iPhone/iPad (Safari): ปุ่มแชร์ > เพิ่มไปยังหน้าจอโฮม

ข้อควรรู้
  - ข้อมูลเก็บในเครื่องตามแต่ละที่อยู่เว็บ ย้ายข้อมูลจากไฟล์เดิมด้วย สำรองข้อมูล > นำเข้าข้อมูล
  - ไฟล์สำรองไม่รวมไฟล์ภาพ ต้องอัปโหลดภาพใหม่
  - แจ้งเตือนทำงานเมื่อเปิดแอปค้างไว้เท่านั้น
  - อัปเดตแอป: แทนที่ไฟล์บนโฮสต์ แล้วเปิดแอป 2 ครั้ง ครั้งแรกโหลดเวอร์ชันใหม่ ครั้งที่สองใช้งานเวอร์ชันใหม่
